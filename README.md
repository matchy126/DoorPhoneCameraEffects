# ドアホンカメラエフェクト

ドアホンのカメラのような、広角でゆがんだ映像を作るページです。映像は端末の中だけで処理され、外には送られません。

## 使い方
1. 「カメラ起動」を押すと、背面カメラで始まります。カメラが複数ある端末では、横のメニューで切り替えられます。
2. 手持ちの写真・動画を使うときは「画像・動画を選ぶ」を押します。
3. 本体の🔔ボタンを押すと、インターホンの「ピンポーン」が鳴って、ページの下に写真が並びます。スマホは長押し、パソコンは右クリックで保存できます。

## 画面の操作
| 項目 | 内容 |
|---|---|
| 縦横比 | 4:3(初期値、640×480)、16:9、3:2、1:1、3:4、9:16 |
| 歪み | 魚眼の強さ。0でふつうの映像。中央が大きく、周辺が縮む |
| 奥行きの傾き | 下が手前・上が奥の面を想定して、遠近感を足す |
| なめらかさ | 細かい模様をつぶす強さ(周辺ほど強い) |
| コントラスト | 明暗の差 |
| 画質劣化 | 色の段階を減らして、絵画のような荒さを出す |
| 色の濃さ | 色の鮮やかさ |
| ノイズ | 細かいザラつき |
| 暗視 | 緑がかった暗視映像に切り替える |
| 画面表示 | 画面のREC・日時の表示を出す・消す |
| 🔔ボタン | 撮影する(ピンポーンと鳴る) |

スライダーの右にある数字の欄に、0〜1の値を直接入れても動きます。

## 加工のしくみ
- レンズ: 等距離射影の魚眼を想定し、ふつうの写真を魚眼の像に変換(中央を拡大、周辺を圧縮)
- 周辺ほど像がぼける、色がずれる(倍率色収差)、暗くなる(周辺光量落ち)
- 1枚の写真には奥行きがないため、「近い物が飛び出す」効果は、傾いた面を想定した遠近感で近似

## 仕様の目安
- レンズ: 水平170°、垂直110°(縦長のときは、縦と横が入れ替わります)
- イメージセンサー: 100万画素(今回の加工では、この細かさまでは再現していません)
- 記録画素数: 640×480px

## 注意
- 画面のREC・日時の表示は、撮った写真には写りません。
- 埋め込み表示ではカメラの許可が出ないことがあります。そのときはリンクをブラウザで直接開いてください。
- 4:3以外では、画像を切り取って縦横比を合わせます。
