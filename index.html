Readme

使い方
「カメラ起動」で背面カメラが始まります(複数あるときは横のメニューで切り替え)。「画像・動画を選ぶ」で手持ちの素材も加工できます。右下の🔔ボタンを押すと、ピンポーンと鳴って、下に写真が並びます。スマホは長押し、パソコンは右クリックで保存してください。

縦横比
4:3(640×480、初期値)のほか、16:9・3:2・1:1・3:4・9:16に変えられます。縦長のときは、170°が縦、110°が横になります。

数値
歪みは魚眼の強さ(0でふつうの映像)です。奥行きの傾きは、下が手前・上が奥になる床のような面を想定して、遠近感を足します。なめらかさは細かい模様をつぶす強さで、周辺ほど強くかかります。コントラストは明暗の差です。スライダーの右の欄に、0〜1の数字を直接入れても動きます。画質劣化は色の段階の少なさ、色の濃さは鮮やかさ、ノイズは細かいザラつきです。

メモ
画面のREC・日時の表示は、写真には写りません。映像は端末の中だけで処理され、外には送られません。
